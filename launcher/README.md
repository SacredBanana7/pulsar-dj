# Pulsar DJ launcher (Windows)

`PulsarLauncher.cs` builds `Pulsar DJ.exe`: a ~20 KB starter that serves the `app` folder on
`http://localhost:5180` and opens it in a Chrome/Edge app window (own profile, no tabs).
The server stops a few seconds after the window is closed.

Build with the C# compiler that ships with Windows (.NET Framework 4):

```bat
launcher\build.cmd
```

The exe must stay next to the `app` folder.
`pulsar.ico` is generated by `tools/make-icon.ps1`.
